Conceptos clave

¿Qué es una función?

Navega por las diapositivas para construir una comprensión sólida, paso a paso.

01

Definición de función

Una función es una relación entre dos conjuntos — el dominio y el codominio — donde a cada elemento del dominio le corresponde exactamente un elemento del codominio.

Lo escribimos como f : A → B, y leemos "f es una función de A en B".

f(x) = y  |  ∀x ∈ A, ∃! y ∈ B
02

Dominio y recorrido

El dominio es el conjunto de todos los valores de x para los que la función está definida. El recorrido (imagen) es el conjunto de todos los valores de y que puede tomar la función.

Por ejemplo, en f(x) = √x el dominio es x ≥ 0, ya que no podemos calcular la raíz de un número negativo (en ℝ).

Dom(f) ⊆ ℝ  |  Im(f) ⊆ ℝ
03

Representación gráfica

La gráfica de una función es el conjunto de puntos (x, f(x)) en el plano cartesiano. Para saber si una curva es función usamos la prueba de la recta vertical: si cualquier recta vertical corta la curva en a lo sumo un punto, es una función.

Gráfica: {(x, f(x)) | x ∈ Dom(f)}
04

Crecimiento y extremos

Una función es creciente en un intervalo si al aumentar x, también aumenta f(x). Es decreciente si al aumentar x, disminuye f(x).

Los máximos y mínimos (extremos relativos) son puntos donde la función cambia de creciente a decreciente o viceversa.

x₁ < x₂ ⟹ f(x₁) < f(x₂)  [creciente]
05

Continuidad y cortes

Una función es continua si su gráfica puede trazarse sin levantar el lápiz. Las raíces son los puntos donde la función corta al eje X (f(x) = 0). La ordenada en el origen es donde corta al eje Y (x = 0).

Raíces: f(x) = 0  |  Ord. origen: f(0)
Clasificación

Tipos de funciones

Desde las más simples hasta las más elaboradas — cada tipo tiene su propia forma, propiedades y aplicaciones en el mundo real.

Tipo 1
Función Constante
f(x) = k

La función constante asigna el mismo valor k para cualquier x. Su gráfica es una recta horizontal paralela al eje X.

Ejemplo real: temperatura de un horno a temperatura estable.

Dom = ℝ Im = {k} Pendiente = 0
Tipo 2
Función Lineal
f(x) = mx

La función lineal pasa siempre por el origen (0,0). El coeficiente m es la pendiente y determina la inclinación de la recta.

Ejemplo: distancia recorrida a velocidad constante (sin punto de partida diferente).

Dom = ℝ Pasa por (0,0) Im = ℝ
Tipo 3
Función Afín
f(x) = mx + b

Igual que la lineal pero con un término independiente b. La recta no pasa por el origen; el valor b indica dónde corta el eje Y.

Ejemplo: factura del teléfono = cuota fija (b) + coste por minuto (m).

Dom = ℝ Corta Y en b Raíz: x = −b/m
Tipo 4
Función Cuadrática
f(x) = ax² + bx + c

Su gráfica es una parábola. Si a > 0 abre hacia arriba (mínimo); si a < 0 abre hacia abajo (máximo). El vértice es el punto más alto o más bajo.

Ejemplo: trayectoria de un proyectil lanzado al aire.

Dom = ℝ Vértice: (−b/2a, …) Parábola
Tipo 5
Función Polinómica
f(x) = aₙxⁿ + … + a₁x + a₀

Generalización de las anteriores con múltiples términos. El grado n determina el comportamiento: puede tener hasta n raíces y hasta n−1 extremos.

Ejemplo: modelos de crecimiento poblacional o curvas de demanda económica.

Tipo 6
Funciones Trigonométricas
f(x) = sen(x), cos(x), tan(x)

Son funciones periódicas — se repiten cada 2π. El seno y coseno tienen valores entre −1 y 1. La tangente tiene asíntotas verticales.

Ejemplos: ondas de sonido, mareas, corriente alterna, movimiento armónico.

Periodo: 2π Im: [−1, 1] Periódica
Tipo 7
Función Racional
f(x) = P(x) / Q(x)

Cociente de dos polinomios. No está definida donde el denominador se anula. Esas x excluidas generan asíntotas verticales; también puede haber asíntotas horizontales.

Ejemplo clásico: f(x) = 1/x (hipérbola equilátera), velocidad media = distancia/tiempo.

Q(x) ≠ 0 Asíntotas Dom ⊂ ℝ
